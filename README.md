# 📈 PricePulse - Stock Price Prediction System

## Overview

PricePulse is a Machine Learning-based Stock Price Prediction System that forecasts future stock prices and provides Buy, Sell, or Hold recommendations. The system utilizes historical stock market data and the Random Forest Regressor algorithm to identify market trends and assist investors in making informed decisions.

## Features

* Historical stock data analysis
* Future stock price prediction
* Buy, Sell, and Hold recommendations
* Interactive web-based interface
* Real-time stock data retrieval
* Trend visualization and performance analysis

## Technology Stack

### Machine Learning

* Python
* Scikit-Learn
* Random Forest Regressor
* Pandas
* NumPy

### Backend

* Flask REST API

### Frontend

* HTML
* CSS
* JavaScript

### Data Source

* Yahoo Finance API

## System Workflow

1. Collect historical stock data.
2. Preprocess and clean the dataset.
3. Train the Random Forest Regressor model.
4. Generate future stock price predictions.
5. Provide Buy, Sell, or Hold recommendations.
6. Display results through a web application.

## Performance Metrics

The model is evaluated using:

* RMSE (Root Mean Square Error)
* MAE (Mean Absolute Error)
* R² Score

## Advantages

* Handles complex stock market patterns.
* Reduces overfitting through ensemble learning.
* Fast prediction performance.
* User-friendly interface.
* Real-time forecasting capability.
